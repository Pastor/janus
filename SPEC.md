# Janus — спецификация

Двухпанельный TUI-файловый менеджер для терминала. Назван в честь двуликого
Януса: две панели смотрят в разные стороны. Бинарник — `janus`.

Прежние имена — `fm` (заняло системной утилитой `/usr/bin/fm` в macOS 27) и
`fmgr`. Конфиг со старых мест (`~/.config/fmgr`, `~/.config/fm`) копируется в
`~/.config/janus` при первом запуске, `make install` убирает старый бинарник
`fmgr` и его строку в настройках оболочки.

## Стек и правила кода

Стек и стиль кода берём из `flob` (`testing/rustlang/large-search`):

- Rust edition 2024, `ratatui 0.30`, `crossbeam-channel` + `rayon` для фоновых задач,
  `trash`, `serde` + `toml`, `dirs`, `anyhow`, `clap`, `unicode-width`, `chrono`.
- Комментарии и документация на русском языке. Каждый модуль начинается с `//!`,
  где объяснено, зачем он нужен и почему сделан именно так.
- Подсветка синтаксиса — собственный построчный лексер, как `highlight.rs` во `flob`.
  Цвет каждому виду токена назначает `ui::theme`.
- Долгие операции (копирование, поиск, архивы, подсчёт размеров) выполняются в фоне
  и не блокируют интерфейс. Прогресс показывается в UI.
- `Ctrl+C` завершает программу всегда, из любого режима.
- `q` в списке файлов — выход, во время операции — её прерывание, в диалогах,
  справке, настройках, просмотре и режиме `l` — то же, что `Esc`. Там, где вводится
  текст (поиск, редактор, имя архива), `q` — обычная буква.
- Если команда нажата в другой раскладке (кириллица вместо латиницы), она не
  выполняется молча: в строке состояния пишется, что раскладка не позволяет её
  выполнить.
- При выходе оболочка переходит в директорию активной панели (из архива — туда,
  где лежит архив). Это делает функция `f`, которую `make install` подключает
  в `~/.zshrc` / `~/.bashrc` / fish: `eval "$(janus --shell-init zsh)"`. Сама
  программа пишет директорию в файл `--cwd-file`.

## Экран

```
╭ /path/left ─────────────────╮╭ /path/right ────────────────╮
│ src/                        ││ ...                         │
│ Cargo.toml                  ││                             │
│ build.sh        (зелёный)   ││                             │
│ link → target   (синий)     ││                             │
╰─────────────────────────────╯╰─────────────────────────────╯
 ↑↓ навигация  Enter открыть  Tab панель  c копия  v перенос  d удалить  ? справка
```

- Две панели, всегда активна ровно одна. Активную панель видно по рамке.
- Внизу строка подсказок. Её содержимое зависит от текущего режима.

## Панель файлов

| Клавиша | Действие |
|---|---|
| `↑` `↓`, `PgUp` `PgDn`, `Home` `End` | перемещение курсора |
| `Enter` | войти в директорию или архив; файл открыть в предпросмотре |
| `→` / `←` | войти в директорию / выйти на уровень выше; `←` в корне — выбор диска |
| `Tab` | переключить активную панель |
| `>` / `<` (Shift) | расширить / сузить активную панель |
| `P` (Shift+p) | скрыть / показать вторую панель |
| `1` `2` `3` | число колонок в активной панели |
| `0` | одна колонка без размера и даты |
| `Shift+←` / `Shift+→` | соседняя колонка (если колонок несколько) |
| `.` | показать / скрыть скрытые файлы |
| `Space` | выделить / снять выделение с файла, курсор переходит к следующему |
| `c` | копировать во вторую панель |
| `v` | переместить во вторую панель |
| `d` | удалить (подтверждение) |
| `D` (Shift+d) | удалить сразу, без корзины (подтверждение) |
| `a` | создать архив |
| `r` / `F2` | переименовать |
| `m` | создать директорию |
| `n` | создать пустой файл |
| `p` | предпросмотр во второй панели |
| `/` | поиск по содержимому |
| `f` | поиск по имени |
| `l` | режим «большие объекты» |
| `g` | выбор диска |
| `o` | настройки |
| `?` | справка |
| `q` | выход |

**Отображение:**

- Директории идут первыми, имя жирное, в конце `/`.
- Исполняемые файлы зелёные, символические ссылки синие, остальное без подсветки.
- Незакоммиченные изменения git (изменённые, добавленные в индекс, удалённые,
  неотслеживаемые) — оранжевым. Внутри рабочего дерева подсвечиваются файлы и
  поддиректории с такими изменениями; вне его — директории-репозитории, в
  которых они есть. Статус считается вызовом `git` в фоне и обновляется при
  каждом перечитывании директории; без git подсветки просто нет.
- Скрытые файлы по умолчанию показываются. `.` переключает их видимость,
  значение по умолчанию задаётся в настройках.
- При 2–3 колонках список перетекает по колонкам, как в `ls`.
- Размер и дата видны только в режиме `1`; в режиме `0` колонка одна,
  но только с именами.

**Копирование и перемещение:**

- Работают только когда видна вторая панель. Цель — её текущая директория.
- Если есть выделенные файлы, обрабатываются они. Если нет — файл под курсором.
- При конфликте имён появляется диалог: «заменить / пропустить / заменить все /
  пропустить все / отмена».
- Прогресс показывается. Операцию можно прервать по `Esc`.

**Удаление:**

- `d` открывает окно подтверждения. Повторное `d` отправляет в корзину, `Esc` отменяет.
- `D` открывает окно подтверждения с явным предупреждением «безвозвратно».
  Повторное `D` удаляет, `Esc` отменяет.

**Переименование (`r` / `F2`):**

- Окно со строкой ввода, в ней текущее имя. Курсор стоит перед расширением
  (у директорий и имён вида `.gitignore` — в конце).
- `←` `→` `Home` `End` — курсор, `Backspace` / `Delete` — стирание, буквы любой
  раскладки — текст. `Enter` переименовывает, `Esc` отменяет.
- Существующее имя не затирается — ошибка в строке состояния. Смена только
  регистра разрешена. Имена с `/` (в Windows и с `\ : * ? " < > |`), пустые,
  `.` и `..` отклоняются.
- Курсор остаётся на элементе с новым именем, обе панели перечитываются.
- Внутри открытого архива запрещено, как и прочие изменения.

**Создание (`m` — директория, `n` — пустой файл):**

- Окно с путём, где создаётся элемент, и пустой строкой ввода; правка — как при
  переименовании. `Enter` создаёт, `Esc` отменяет.
- Существующее имя не затирается — ошибка в строке состояния. Недопустимые имена
  отклоняются по тем же правилам, что при переименовании.
- Курсор переходит на созданный элемент, обе панели перечитываются.
- Внутри открытого архива запрещено.

## Предпросмотр

Вызывается клавишей `p` из панели файлов. Превью открывается во **второй** (неактивной)
панели и следит за курсором: показывает файл, на котором он стоит. Предпросмотром
может быть только одна панель. Если вторая панель скрыта, `p` её показывает.

| Клавиша | Действие |
|---|---|
| `p` / `Esc` | закрыть предпросмотр |
| `Tab` | перейти в панель предпросмотра и обратно |
| `↑` `↓`, `PgUp` `PgDn`, `Home` `End` | прокрутка (когда фокус в предпросмотре) |
| `w` | переключить soft wrap (по умолчанию включён) |
| `e` | режим правки |
| `/` | поиск по тексту |

- **Текстовый файл:** подсветка синтаксиса. Для исходников выводятся номера строк.
- **Директория:** путь, число файлов и поддиректорий, суммарный размер
  (считается в фоне), права, владелец, даты, крупнейшие элементы.
- **Бинарный файл:** тип, размер, права, даты, hex-дамп начала файла.
- **Архив:** список содержимого.

### Поиск по тексту (`/` в предпросмотре)

- Внизу появляется строка ввода. Поиск идёт по мере набора, курсор сразу переходит
  к первому совпадению. Строка с совпадением ставится по центру экрана.
- `←` / `→` переходят к предыдущему / следующему совпадению.
  В строке показывается счётчик `3/17`.
- `Esc` выходит из режима поиска.

### Подсветка

| Категория | Что входит |
|---|---|
| Языки | Rust, C/C++, Go, Java, Kotlin, Python, JS/TS, Lua, Ruby, Shell, Swift, C#, PHP |
| Разметка | Markdown, HTML, XML, CSS |
| Данные и настройки | JSON, YAML, TOML, INI, `.properties`, `.env`, `.editorconfig` |
| Прочее | SQL, Dockerfile, Makefile, `.gitignore` / `.dockerignore` / `*ignore`, diff/patch |
| Логи | `*.log`, а также файлы, похожие на лог по содержимому |

Формат определяется по имени и расширению. Если их нет — по shebang и первым строкам.

Что подсвечивается в логах:

- уровни: `ERROR`/`FATAL` красным, `WARN` жёлтым, `INFO` обычным цветом,
  `DEBUG`/`TRACE` приглушённо;
- временные метки;
- IP-адреса, URL;
- числа, строки в кавычках;
- stack trace.

Что подсвечивается в файлах настроек:

- секции;
- ключи;
- значения: строки, числа, булевы;
- комментарии.

## Редактор

Вызывается клавишей `e` из предпросмотра.

| Клавиша | Действие |
|---|---|
| стрелки, `Home` `End`, `PgUp` `PgDn` | перемещение курсора |
| ввод текста, `Backspace`, `Delete`, `Enter` | правка |
| `Tab` / `Shift+Tab` | отступ / снять отступ |
| `Ctrl+S` | сохранить (с подтверждением) |
| `Esc` | выход. Если есть изменения — «сохранить / не сохранять / отмена» |

**Отступы:**

- `Enter` сохраняет отступ текущей строки.
- После `{`, `(`, `[`, `:` (Python) отступ увеличивается.
- Размер отступа определяется так:
  1. по `.editorconfig`, если он есть;
  2. автоматически, по уже имеющимся строкам файла;
  3. по языку:
     - 4 пробела — Rust, Python, C/C++, Java, Kotlin, C#, Swift, PHP, Shell;
     - 2 пробела — JS/TS, JSON, YAML, HTML, CSS, Lua, Ruby, Markdown;
     - табуляция — Go, Makefile;
     - для остальных — 4 пробела.

## Поиск в панели файлов

**По содержимому (`/`):**

- Внизу строка ввода. Поиск идёт рекурсивно по всему поддереву текущей директории
  в фоне. `.gitignore` не учитывается, бинарные файлы пропускаются. Скрытые
  файлы ищутся по той же настройке, что и в панели (`.`).
- Регистр учитывается, только если в запросе есть заглавные буквы. Это правило
  общее для всех поисков: в файлах, по именам и в просмотре.
- Вторая панель (если она видна) показывает файл на найденной строке.
  Совпадение подсвечено и стоит по центру экрана.
- `↑` / `↓` переходят по совпадениям, в том числе между файлами.
  `Enter` переходит к файлу в панели.
- `Esc` выходит из режима поиска.

**По имени (`f`):** то же самое, но совпадения ищутся в именах файлов
(подстрока, регистр — по тому же правилу). Вторая панель показывает найденный файл.

## Архивы

- **Открытие:** `Enter` на архиве распаковывает его во временную директорию,
  панель работает в ней как в обычной папке. Путь в заголовке показывается
  как `archive.zip/…`. При выходе из архива и при завершении программы временная
  директория удаляется.
- **Форматы:** zip, tar, gz, tar.gz/tgz, tar.zst. RAR и 7z открываются через внешнюю
  утилиту `unrar`, `7z`/`7zz` или `bsdtar`, если она установлена; иначе показывается
  сообщение.
- **Только чтение:** копирование и перенос внутрь открытого архива, правка его
  файлов и создание в нём архивов запрещены — изменения не попали бы в архив.
  Копировать из архива наружу можно.
- **Создание (`a`):** диалог выбора формата (zip, tar, tar.gz, tar.zst) и имени архива.
  Архивируются выделенные файлы или элемент под курсором. Архив создаётся в
  текущей директории. `Esc` отменяет.

## Режим «большие объекты» (`l`)

- Окно на весь экран, как во `flob`: рекурсивный подсчёт размеров в фоне,
  сортировка по убыванию, полоска доли и процент, цветовой градиент по размеру.
- `↑` `↓` перемещают курсор, `→`/`Enter` входят в директорию, `←` выходят наверх.
  Предпросмотра файлов нет.
- `d`/`D` удаляют объект под курсором (в корзину/безвозвратно) с тем же
  подтверждением, что и в панелях. Удалённый объект пропадает из дерева, размеры
  предков пересчитываются без повторного сканирования.
- `Esc` возвращает в основной режим. Директория, в которой был курсор, открывается
  в активной панели.

## Выбор диска (`g`)

- Окно со списком дисков для активной панели. Открывается по `g` или по `←`
  в корне файловой системы: в Windows из `C:\` иначе на другой диск не попасть.
- **Windows:** диски из `GetLogicalDrives` — буква, тип (диск, съёмный, сетевой,
  CD/DVD), метка тома, полоска заполнения, свободное место из общего. Буква
  диска сразу переходит на него (кроме `q` — это `Esc`). Системное окно
  «Вставьте диск» для пустых приводов подавлено; у сетевых дисков место не
  запрашивается, чтобы отключённая шара не подвешивала окно.
- **macOS:** `/`, домашняя директория и тома из `/Volumes`.
- **Linux:** `/`, домашняя директория и блочные устройства из `/proc/mounts`
  без служебных (`/boot`, snap).
- Курсор сразу стоит на диске текущей директории. `↑` `↓` — выбор,
  `Enter` / `→` — перейти, `Esc` / `q` / `←` — закрыть.

## Справка и подсказки

- Нижняя строка показывает только те клавиши, которые в текущий момент что-то
  сделают (например, `c`/`v` — только если есть куда копировать). Если они не
  помещаются в одну строку, подсказки занимают две; не влезшее и во вторую
  заменяется `…`.
- `?` открывает окно справки со всеми клавишами, сгруппированными по режимам.
  Окно прокручивается. `Esc` или `?` закрывает его.

## Настройки (`o`)

Окно настроек:

- язык: English (по умолчанию) / Русский;
- тема: Dark (по умолчанию), Light, Gruvbox, Solarized, Nord;
- soft wrap по умолчанию;
- показ скрытых файлов;
- размер отступа по умолчанию;
- удаление в корзину или безвозвратно по умолчанию.

Настройки сохраняются в `~/.config/janus/config.toml`. Туда же записывается состояние
сессии: ширина панелей, число колонок, последние директории.

Ключи `-t` / `-l` меняют тему и язык только на текущий запуск: при выходе в файл
пишутся прежние значения. Постоянными они становятся, только если сохранить
настройки в окне `o` по `Enter`.

## Локализация

- Все строки интерфейса берутся из таблиц `en` и `ru`. Язык по умолчанию — `en`.
- Добавление нового языка — это одна новая таблица, без правок логики.

## Этапы

1. Каркас:
   - две панели, навигация, колонки, ресайз, скрытие панели;
   - цвета, темы, i18n, конфиг, строка подсказок.
2. Выделение, копирование и перемещение с диалогом конфликтов, удаление в корзину
   и безвозвратное.
3. Предпросмотр:
   - подсветка, номера строк, wrap;
   - поиск по тексту;
   - информация о директориях.
4. Редактор.
5. Поиск по содержимому и по имени.
6. Архивы: открытие и создание.
7. Режим `l`.
8. Справка `?`, окно настроек, доводка.
